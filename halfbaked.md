# halfbaked.md — What's Faked, Partial, or Not Yet Working

This file tracks every shortcut, stand-in and known gap in the project, so judges can see exactly what is real.
Status key: **DONE** = working and verified · **FAKE** = invented or simulated data · **PARTIAL** = real but limited scope · **BROKEN** = written but won't run as-is · **NOT RUN** = never executed or verified · **NOT DONE** = planned, not built

_Last updated: 2026-10-16 (CoCo session 2)_
